## 交付

在当前目录生成：

- `index.html`：单页可点击原型（内联 CSS/JS 即可，或同目录 `styles.css` + `app.js`）
- 用浏览器直接打开就能点完主流程
- 中文界面
- 预填黄金用例数据，打开即看到盘，不是空白表单

禁止：后端、构建工具、node_modules、紫色渐变、Inter/Roboto、通用 AI 仪表盘风。

## 谁用

红娘机构老师。他们已经在用「问真八字」。我们要让老师 **一眼认出细盘结构**，同时看清我们比问真多的三件事：口径可切换、计算过程可审计、和问真的差异被标成「表不同」而不是排盘错误。

参考截图：`refs/wenzhen-chart.jpg`（信息架构必须对齐，不要像素级抄图标/商标）。

## 视觉方向

专业命理工作台，不是算命娱乐站。

- 深墨底 + 牙纸色内容区 + 金色点缀（类似问真：顶栏黑金，盘面浅灰表格）
- 天干五行着色：木绿、火红、土黄、金暗金、水蓝
- 字体：标题用思源宋体 / Noto Serif SC，正文用 Noto Sans SC（Google Fonts）
- 手机优先（红娘老师常用手机），也要能在 1280 桌面看
- 密度高，信息要排得下，不要大卡片留白

## 信息架构（4 个 Tab，对齐问真）

1. **基本信息**
2. **基本排盘** ← 默认打开，核心验收页
3. **专业细盘**（本期只做壳：大运流年用「二期」灰显占位）
4. **断事笔记**

顶栏另有两个老师工具（问真没有，我们的差异化）：

- **口径**（抽屉/底部 sheet）
- **对照**（问真 vs 本盘 差异）

## 页面规格

### 1) 基本信息

- 姓名、性别（乾造/坤造）、出生地（搜索示意，预填兰州）
- 历法切换：公历 / 农历
- 日期时间到分钟
- 小字展示换算后的另一套历法
- 主按钮「排盘」→ 切到基本排盘（原型里数据已在，点了给轻微反馈即可）

### 2) 基本排盘（最重要）

结构贴近 `refs/wenzhen-chart.jpg`：

- 顶部命主条：头像/生肖鼠、姓名、农历、阳历、乾坤造
- 右侧小图标：显示/隐藏、编辑（示意）
- **四列表格**：日期 | 年柱 | 月柱 | 日柱 | 时柱
- 行：主星、天干（带五行图标）、地支、藏干、副星、星运、自坐、空亡、纳音、神煞
- 神煞可换行，金色小字
- 点某一柱，底部弹出该柱口诀来源（例如桃花：「亥卯未见子，日支查」）

顶部工具条：

- 开关 **真太阳时**（默认关，对齐问真；打开切到口径 B，时柱高亮闪一下）
- 开关 **子时流派**（流派1 子初换日 / 流派2 早晚子时）本盘 12:03 无差异，旁注「本命不在子时交界」
- 按钮 **计算过程** 展开审计

审计条（可折叠，默认展开一次让老师看见）：

```
北京时间 12:03:00
→ 夏令时：未命中（1996，非 1986–1991）
→ 经度差 (103.82−120)×4 = −64.7 分
→ 均时差 −4.8 分
→ 真太阳时 10:53:48（仅当开关打开才应用到四柱）
→ 立秋 1996-08-07 约 14 时已过，月柱申
→ 子时政策：未触发
```

交界预警：本盘距午/巳交界 11:00 还远，显示绿点「非交界」。另做一条演示：点「看交界示例」切到 11:05 的假数据，黄条「距时辰交界 5 分钟」。

### 3) 专业细盘

大运流年时间轴占位，卡片写「二期 · 起运与流年」。不要假造十年大运数字让老师以为已经准了。

可放五行个数示意（丙2 己1 庚1 / 子申卯午）但不做喜用神断语。

### 4) 断事笔记

老师手写备注列表 + 输入框。预填一条：「问真未开真太阳时，兰州 12:03 时柱或为巳。」
不要 AI 批命。

### 5) 口径抽屉

三项，带我们已冻结的默认：

- 真太阳时：开 / 关（默认关以对齐问真截图；说明「西部建议开」）
- 子时：流派1 子初换日（问真同款，默认） / 流派2 早晚子时
- 节气：年/月柱用北京时间交节（寿星常用，默认，不可在原型里改成复杂第三项，灰色说明即可）

每项一句话解释。改开关立刻反映到盘面（至少真太阳时必须联动）。

### 6) 对照页

两列：问真口径（真太阳时关） | 本盘当前口径

只高亮不同的柱。本例打开真太阳时后，时柱红/金框标「不一致」。
底部说明：神煞条数不同标「表不同」，四柱不同标「口径/历法」。

## 交互必须能点

- Tab 切换
- 真太阳时开关改变时柱
- 计算过程展开/收起
- 点神煞看出处
- 口径抽屉
- 对照页
- 断事笔记能输入一条并出现在列表（内存即可）
