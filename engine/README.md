# 历法引擎 · §9 第 1 步

公历 → 四柱，带夏令时 / 真太阳时 / 子时两派三层可切换校正与逐步审计。

```bash
npm install
npm run golden   # 打印 10 个黄金用例（带断言）
npm test         # 11 条回归
```

## 分层

```
钟表时（出生记录原样）
  ─[夏令时回拨]→  标准北京时  ──→ 年柱、月柱（按北京时间交节）
  ─[+经度差 +均时差]→ 真太阳时  ──→ 日柱、时柱
```

年月柱不走真太阳时，是 §3.1 冻结的口径（寿星万年历常用方案），业内不统一，故写死并可审计。

## 模块

| 文件 | 内容 |
|---|---|
| `src/dst.js` | 1986–1991 夏令时表 + 四类边界分类 |
| `src/solartime.js` | 均时差（NOAA/Meeus）+ 经度差 + 儒略日 |
| `src/tables.js` | 十神 / 藏干 / 十二长生（自研，不取自 GPL 实现） |
| `src/chart.js` | 编排 + 细盘十行 + 审计 JSON |

历法底座用 `lunar-javascript`（MIT）。十神、藏干、星运、自坐由 `tables.js` 自算，因为
年月柱与日时柱可能来自两个不同时刻，库内置的十神会按错误的日干计算。

## 两个必须记住的坑

**1988 年夏令时起日是 04-17，不是 04-10。**
国办 1987-09-09 的规则是「4 月中旬第一个星期日」，中旬 = 11–20 日。命理博客和
部分同类产品普遍抄成 04-10。按错表，1988-04-10～04-16 出生者会被多减一小时、
时柱整柱反错。见 `src/dst.js` 顶部注释与测试「1988 起日必须是 04-17」。

**夏令时结束日 01:00–01:59 走两遍。**
同一钟表时对应两个瞬间，「日期 + 钟表时 + 出生地」不足以唯一表示。`timeFold`
为 `unknown` 时输出**双盘**，不猜。见测试「重复小时且 fold 未知」。

## 已知微小差异

兰州 1986-06-15 11:00，本引擎算 09:55，问真 Web 版显示 09:54，差 1 分钟。远在
时辰精度（120 分钟）之下，但对盘时会看到，记录在此。
