## 1. 文档本身的三个问题（先说清，否则后面都白做）

### 1.1 文档在第十一章处断了
docx 正文到「第十一章：真冲与虚冲判定 / 类型」就结束，后面只剩表头。`word/document.xml` 在第十一章之后只有 23 个文本节点，全是表头与页脚。标题写「（基础）」，说明还有下卷。**要向老师要完整版**，至少要第十一章与下卷的算法主流程。

### 1.2 页脚标注「部分内容可能由 AI 生成」
文档里所有**数值**都需要老师确认是本人口径，而不是 AI 补的：

| 数值 | 位置 |
|---|---|
| 藏干比例 60/30/10、70/30、100 | 第一章 |
| 宫位权重 月 1.5 / 日 1.2 / 时 0.8 / 年 0.6 | 第二章 |
| 距离权重 相邻 100% / 隔一位 40%（断事）70%（断局）/ 隔两位 0% | 第三章 |
| 岁运权重 大运 0.6 / 流年 1.0 / 流月 0.3 | 第五章 |
| 三合「月令死绝打七折」、三会「仅存三四成」 | 第十章法则四 |

传统藏干论「人元司令分野」是按**天数**分（如寅：戊 7 日、丙 7 日、甲 16 日），不是 60/30/10 的百分比。这套百分比是本模型自定义的，可以用，但必须是老师自己定的。

### 1.3 与现有引擎、与问真的口径差
| 项 | 老师文档 | 本引擎 `engine/src/tables.js` | 问真截图 |
|---|---|---|---|
| 巳 藏干（本/中/余） | 丙 / **戊** / **庚** | 丙 / 庚 / 戊 | 丙 / 庚 / 戊 |
| 暗合 | 只列 寅丑、午亥 两对 | 未实现 | — |
| 三刑 | 启用自刑（有开关） | 未实现 | — |

巳的中气与余气谁先谁后，直接影响细盘「藏干」「副星」两行的顺序，也影响文档里 30%/10% 的权重归属。**要老师拍板**。

## 2. A 标注层：现在就能做的部分

### 2.1 做什么
对原局四个地支，算出并展示：

| 类别 | 条目 | 文档代号 | 备注 |
|---|---|---|---|
| 两支关系 | 六合、六冲、六害、六破、暗合、（无礼之刑 子卯） | K03 K09 K11 K12 K07 K10 | 纯查表 |
| 三支格局 | 三会、三合、生旺半合、旺墓半合、暗拱 | K01 K02 K04 K05 K06 | 三合/三会四柱内三支齐全即标；半合与暗拱按长生/帝旺/墓库位判 |
| 三刑 | 寅巳申、丑戌未（三支或任两支）、自刑（辰午酉亥重见） | K10 | 丑戌未「天干重克则仅虚象」需要天干模块，本层**只标不修正**，备注「待天干模块」 |
| 伏吟 | 原局同支重见 | V01 | 静态 |
| 墓库 | 辰戌丑未标「墓库 · X 库」 | 第七章 | 开闭状态属 B 层 |
| 争合 | 同一支被两支来合 | K08 | 只标「争合」，裁决属 B 层 |

每条关系附带三个标签，全部来自文档编码表：
- **位置**：涉及哪几柱（年/月/日/时）；
- **距离档**：D10 相邻 / D11 隔一位 / D12 隔两位，两套百分比（断事 / 断局）一起标；
- **金字塔等级**：K 代号与星级。

### 2.2 展示
- 细盘表格**下方**新增「地支关系」区块，不改 `DETAIL_ROWS`（老师肌肉记忆行序，契约里写死勿改）。
- 每条关系可点，弹出文档里的规则原文与代号（同神煞区「点击看口诀」的交互）。
- 区块底部常驻声明：「关系表据老师《地支运算体系 V3.1》冻结；暗合、自刑、藏干比例为本模型口径，可在口径抽屉切换」。
- 三支格局在四柱里画一条连线或用同色底衬标出三个格子。

## 3. B 判定层：能算，但规则先要补齐

法则一到六在**原局静态**场景下原则上可算，做法是给每条 A 层关系加一个「状态」字段（S00 正常做功 / S01 被封印 / S02 被通关化解 / 合绊 / 被解），并附「因为哪条法则」。但下面这些边界文档没写，程序无法自圆其说，**每一条都要老师回答**：

| # | 缺口 | 在哪 |
|---|---|---|
| B1 | 六合只有两支，没有「中神」。法则二「冲破合必须冲中神」怎么套到六合上？ | 法则二 |
| B2 | 三合/三会三支必然分布在四柱里，「贴身」「同等距离等级」对三支格局怎么算？（如年月日三合，时支来冲，算贴身冲中神吗） | 第九章前置约束、法则五 |
| B3 | 化气条件②「天干引透」④「本根未绝」、法则四「天干多重克泄」、丑戌未刑「本气被重克」，都要**天干模块**给出「克泄程度」。文档自己声明天干是独立模块，但没有接口定义 | 法则三、四；K10 |
| B4 | 争合「一去争两，能量分散」的距离与宫位规则未给（只给了「两争一」的） | K08 |
| B5 | 封印解除后「视剩余格局强弱而定」、G01「本气越冲越旺」——无量化，程序只能给定性标签 | 第六、七章 |
| B6 | 「断具体事件」与「断人生大局」两套距离权重，产品默认按哪套？ | 第三章 |
| B7 | 流派开关默认值：自刑开/关、六合墓库「合闭」还是「收纳」 | 第七、九章备注 |

建议：B 层每条法则做成**独立开关**（文档自己预留了「程序开关」），默认全关，老师在口径抽屉里逐条打开验证。等 B1–B7 有答复再排期。

## 4. C 岁运层：等二期

第五章（大运 ×0.6 / 流年 ×1.0 / 流月 ×0.3、太岁特权）、第八章反吟、第六章封印解除、第十一章真冲虚冲，全部依赖大运流年。调研方案 §6 把大运流年定为二期，试用说明也明确写了「不做大运流年」。**A 层的输出结构要为它预留**：`Relation` 里加 `layer: 'T00'|'T10'|'T20'|'T30'` 字段，现在只填 T00。
