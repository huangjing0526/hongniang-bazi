## 目标

**老师能录入命例、看到完整细盘、当场提交裁定。** 不是做一个更好的排盘器。

背景（决定优先级，务必读）：机构自述「问真 98% 是对的，只有部分场景有错」。所以我们不是来替代问真的——老师主力仍在问真，拿不放心的盘来我们这儿过一遍。成功标准是**老师愿意持续拿命例过来测**。一切设计围绕「降低回访摩擦」。

## 技术

`web/` 新建。静态页优先，可用 Vite，也可纯 HTML + ESM 直接 `import` engine 的 `src/`。**不做后端、不做账号、不设登录墙。** 状态存 localStorage。

引擎入口：
```js
import { computeChart } from '../engine/src/chart.js';
const { charts, warnings } = computeChart({
  year, month, day, hour, minute,
  longitude, applyDst, applyTrueSolar, sect, timeFold, gender,
});
```
`charts` 长度可能是 2（夏令时结束日重复小时），两盘都要渲染，不要只取第一个。

## 按优先级从上到下做

### 1. 快速输入（最高优先级）

老师手上是一批命例，录入慢到第三个就不来了。

- **主路径**：`199303270255` 一串数字直接解析成 1993-03-27 02:55。问真已有此设计，抄它。
- **批量粘贴**：一个 textarea，一行一个命例，解析后成列表逐个排。
- 日期滚轮是次要路径，不是主路径。
- 出生地用 `engine/src/city.js` 的 `lookupCity(query)`（轨 A 正在做，先按契约里的 `City` 形状写，函数没好就先 mock）。

### 2. 第一屏分歧风险条

**这是老师复访的唯一理由。** 98% 一致是常态，如果连排十盘我们都跟问真一样，他不会再来。

渲染 `chart.risks`（`Risk[]`，六种 `RISK_KIND`），常驻在盘的正上方。无风险时也要有一行「本盘不在已知分歧区」，不要留空——那同样是信息。

### 3. 细盘表格

- 行序严格按 `DETAIL_ROWS`（老师肌肉记忆，勿改）：主星 天干 地支 藏干 副星 星运 自坐 空亡 纳音 神煞
- 天干五行着色（§8 令牌表）
- 神煞金色小字，点击展示 `shenSha[].source` 口诀出处
- `pendingTeacherConfirm` 为 true 的神煞旁标「表源待老师确认」
- **神煞区常驻一行说明**：「本表为冻结表，与其他工具的条目差异属表不同，不是漏算」（§7.3，问真的神煞更多，不加这句会被判成功能缺失）

### 4. 老师裁定表单（取代原「断事笔记」）

按 §13.2 与契约里的 `Verdict`：

- 分歧柱（年/月/日/时，可多选；也要能选「与我们一致」）
- 老师认为正确的干支（仅分歧柱）
- 依据流派（下拉 + 自由填）
- **时间来源**（出生证 / 家人口述 / 客户自报）—— **必填**。这是唯一能把「输入本身就错」和「历法口径不同」分开的字段，事后补不回来
- 一句话理由

存 localStorage，能列出、能导出 JSON。**「与我们一致」的记录同样要能提交**——它构成 98% 的分母。

### 5. 口径抽屉 + 对照页

- 三个开关：真太阳时 / 夏令时 / 子时流派，改动**实时重排**
- 对照页：两套口径并排，只高亮不同柱
- 计算过程：渲染 `chart.audit`，做成左侧朱线的「朱批」，不要仪表盘日志

### 6. 一条红线

分歧时**不给「正确答案是 Y」**，只给「分歧点在 X」+ 两种口径的盘并排。可以给反推特征差异（如「按巳时断偏比肩，按午时断偏伤官」）让老师自己判，但不给倾向性建议。
