## 要画的东西

### 1. 关系区主体（F-3、F-4、F-6、F-11）

- 位置：细盘十行表格 → 神煞说明 → **关系区** → 卷宗结束。
- 分四组：**三支格局 / 两支关系 / 整柱 / 墓库**，组内强者在前（数据已排好序，原型按序画即可）。整柱一组是盖头、截脚、天合地合、天克地冲（反吟）、干支伏吟，文字条目（`chart.pillarRelations`）。
- 每条条目至少显示：地支（如「巳酉」）、名目（如「生旺半合（半合金）」）、落在哪几柱（如「月·日」）、
  隔位时标「隔一位 / 隔两位」。相邻不标。
- 三种色调：合类金系、冲刑害破朱砂系、墓库与伏吟中性。数据里 `nature` 字段给的是 `bond / clash / neutral`。
- 待确认条目（`pendingTeacherConfirm`）沿用神煞的 `*` 号约定。
- 空态：一行「本盘四支之间无合冲刑害破，亦无墓库」。
- 区底常驻一行说明，文案见 PRD F-10，措辞可润色，意思不能变。

用这三个盘做样张，覆盖多数条目类型：

| 盘 | 四柱 | 会出现的关系 |
|---|---|---|
| 案例 9 | 丙子 癸巳 辛酉 戊子 | 巳酉 生旺半合（月·日）；子酉 六破（年·日，隔一位）；酉子 六破（日·时）；子子 伏吟（年·时，隔两位） |
| 案例 3 | 乙亥 己丑 戊申 乙卯 | 亥卯 生旺半合（年·时，隔两位）；亥申 六害（年·日，隔一位）；丑 金库 |
| 构造盘 | 地支 寅 巳 申 子 | 寅巳申 三刑（恃势之刑，三支相连）；寅申 六冲（年·日，隔一位）；寅巳 六害（年·月）；巳申 六合（合水）+ 六破（月·日） |

第三个盘是故意挑的：同一对地支「巳申」既六合又六破，原型要能并列两条而不显得像重复。

### 2. 条目弹层（F-5）

复用神煞弹层的壳（同一个浮层、同一个关闭方式、同样的焦点处理），内容五行：

1. 标题：地支 + 名目，待确认时带「口径待老师确认」小标
2. 位置：`月支（月令）巳、日支（夫妻宫）酉`
3. 距离：两支 → `相邻 / 隔一位 / 隔两位`；三支 → `三支相连 / 三支有隔`；争合与墓库没有这一行
4. 规则原文（数据里 `source` 字段，一到两句）

**不显示**代号、星级、任何百分比（一期决策 D-13：只标关系名）。

### 3. 工具栏「自刑」开关（F-8）

在「子初换日 / 早晚子时」之后加一个勾选「自刑」，默认勾上。悬停提示一句：
「辰午酉亥重见才算。老师模型默认开，部分流派不认；只影响下方关系区，不改四柱」。
不需要新的视觉语言，跟现有两个勾选一致。

### 4. 格上的线（F-7、F-14、F-15、F-16，**必做**）

老师看过小南斗的灰线后要的就是这个。规则已经在 PRD BR-12～16 定死，你只定视觉：

**a. 生克流通线（F-14）**，只画三处：同柱天干↔地支（竖）、相邻柱天干之间（横）、相邻柱地支之间（横）。
- 生：细灰箭头，从生的一方指向被生的一方
- 同五行：细灰平线，无箭头
- 克：**不画**
- 隔柱不画

**b. 合冲托底线（F-7、F-15）**，不论隔几柱都画：
- 地支六合、六冲、三合、三会；天干五合（甲己土、乙庚金、丙辛水、丁壬木、戊癸火）
- 托底线上一个字：合标所合五行（「木」「土」），冲标「冲」，三合三会标「合木」「会水」之类
- 害、破、刑、半合、暗拱、伏吟、争合**不画**（BR-16 默认，老师看过原型再定）

**c. 克的文字行（F-16）**：关系区里加一行「天干本命：己克癸、癸克丁」式短文。列的是**年月时三个天干各自与日主之间**的克，不论距离——「本命」就是日主：己（年干）克日主癸、日主癸克丁（月干）。相邻三处的克不列。

**d. 宫位小字（F-17）**：表头「年柱 / 月柱 / 日柱 / 时柱」下一行小字：祖上宫 / 月令 / 夫妻宫 / 子女宫。**不加年龄段**。

线的克制是重点：细、灰、不抢干支主字；线与字之间留呼吸；两条线交叉时（如天干合的托底线跨过中间柱）
要能分清。参考图 01 是线最多的例子，照着它的密度做上限。

再加两个样张，它们在参考图里有现成的正确答案，可以对着核：

| 盘 | 四柱 | 应画的线（对照参考图 01 / 06） |
|---|---|---|
| 小南斗例一 | 丁丑 庚戌 壬寅 庚子 | 竖：丁↓丑、戌↑庚、壬↓寅、庚↓子；横：庚→壬、庚→壬（时干到日干）、子→寅；平线：丑—戌；托底：丁 ⌐ 壬「木」 |
| 小南斗例二 | 己卯 丁丑 癸酉 癸丑 | 竖：丁↓丑、酉↑癸；横：丁→己、丑→酉、丑→酉（时支到日支）；平线：癸—癸；托底：卯 ⌐ 酉「冲」；文字行：天干本命：己克癸、癸克丁（己是年干，与日主隔一位，照列） |

### 5. 两个宽度都要画（F-12）

- 375px 单栏：条目换行不截断。
- 1024px 双栏：关系区不能把右栏「老师当场裁定」顶出首屏。
  若五个样盘里最长的那个（构造盘，约 6 条，外加格上的线）会顶出去，给出折叠 / 收纳方案。

## 不要做的

- 不画 B 层（合解冲、封印、化气）与岁运（大运流年）的任何占位。PRD §5 非目标。
- 不画五行百分比圆环、格局、喜用、年龄段。PRD §5 非目标 7、8。
- 不给线加粗细或百分比来表示强弱——线只说「有」，不说「多强」（PRD R-8）。
- 不画「地支关系异议」按钮或表单字段。本期反馈走裁定表单的一句话理由。
- 不改神煞区、不改十行表格、不改风险条。
