## 一、万年历核盘从「一个去处」改成「一行结论」

### 为什么改

万年历早就自动跟着当前盘走（`runCompute` 与切 tab 都会 `syncAlmanacFromChart`），
所以问题从来不是数据，是**它住在独立 tab 里**。实测 1440px、1990-03-06（惊蛰当天）：

| | 盘页 | 点「查看万年历 →」之后 |
|---|---|---|
| 四柱表 | 首屏内 | 看不见 |
| 风险条 | 可见 | 看不见 |
| 裁定表单 | 首屏内（y=179） | 看不见 |

老师正拿这三样互相对照，一次点击把三样全换走。而换回来的「对照结论」只有
**178px、4 个格子**，其余 2200px（月历格 537 / 本月节气 231 / 本地时辰表 610 /
来源声明 166）是好东西，但不是他此刻问的问题。

**他用整个上下文，换 4 个写着「一致」的格子。**

### 改成什么

万年历在干两件事，现在分开放：

- **翻历**（脱离命例查某年某月）→ 独立 tab 不动，工具栏的「对照万年历 →」也不动
- **核盘**（写裁定写到一半要对个账）→ 不再是去处，直接算在风险条末尾

`renderRisks()` 末尾新增 `renderAlmanacCrossCheck()`：只在存在历法类风险
（`ALMANAC_RISK_KINDS`）时出现，一致就一行字，有出入才摊开分歧的那几柱并标红。
原来每条风险后面挂的「查看万年历 →」撤掉了——同一个去处不必给两个入口，
末尾保留一个「完整万年历 →」给真要翻月历的人。

### 取舍

- **只渲染一次，不逐条挂**：一张盘可能同时有 `JIE_QI_DAY` 和 `JIE_QI` 两条风险，
  逐条挂就是同一句话说两遍。
- **一致时不摊开四柱**：多数情况答案就是「一致」，摊开四个格子只是噪声。
  老师要的是「有没有出入」这一个判断。
- **算不出来时明说「暂时算不出」**，不静默吞掉，也不装作核过了；
  错误上下文（`caseId`）照全局规矩先落 `console.error`。

## 二、ARIA 三处

| 缺口 | 补法 |
|---|---|
| `.tab-pane` 没有 `role="tabpanel"` | 5 个面板补 `role` + `aria-labelledby` 指回各自的标签，并给 `tabindex="0"`（面板内有可滚内容，键盘用户要能滚它） |
| toast 没有 live region | `role="status"` + `aria-live="polite"` + `aria-atomic`。用 polite 不用 assertive：toast 是「已保存」这类回执，不该打断老师正在念的那句 |
| tab 不支持左右箭头 | `initTabKeyboard()`：←/→/Home/End，配 roving tabindex |

**roving tabindex 是行为变更，要留意**：`role="tablist"` 许诺的就是「Tab 键进来一次，
之后左右键在标签间走」，所以现在只有当前标签在 Tab 序列里，其余 `tabindex="-1"`。
读屏用户拿到的是标准行为；但纯键盘用户如果习惯了一路 Tab 穿过五个标签，会觉得变了。
若不接受这条，可以只留箭头、把 roving 去掉（`syncTabRovingIndex` 删掉即可），
但那样 `role="tablist"` 就名不副实。

## 三、`--sticky-top` 从写死改成实测

回执里 Antigravity 报的是「150% 字号下遮挡约 20px」，实测比这更早发作：

| 浏览器字号 | header 实高 | 原 `--sticky-top` | 差 |
|---|---|---|---|
| 16px（默认） | 131px | 128px | **-3px** |
| 20px（125%） | 147px | 128px | -19px |
| 24px（150%） | 164px | 128px | -36px |

**默认字号下就已经差 3px**，吸顶的裁定框一直压在顶栏底下一点。
`initStickyTop()` 用 `ResizeObserver` 盯住 `.main-header`，把实高写进 `--sticky-top`；
字号、窗宽、同步状态那行的字数变化都能跟上。CSS 里的 `128px` 留作 fallback。

## 四、验证

`npm test` 36/36，`npm run build` 18 个文件。以下全部真实按键 / 真实浏览器实测：

- **万年历内联**：节气盘出现对照行且盘与裁定表单都还在；普通盘不出现；
  只剩一个「完整万年历」入口；不一致分支的四柱格在 1440 与 375 两个宽度下都不越界
- **ARIA**：5 个面板语义齐全；toast 是 `status`/`polite`；roving tabindex 只有 1 个 0；
  ←/→/Home/End 四个键都实测切页成功
- **sticky-top**：16/20/24px 三档下 `--sticky-top` 与 header 实高差均为 0

两张 1024 宽的变化已查明并**属预期**：只有 768 高的视口会让裁定框顶到

131，max-height 从 580px 变 577px、内滚区 314→311px。1080/1440 都是 900 高、
裁定框够放，所以零差异。样盘 1 没有历法类风险，万年历那条在这组图里的像素贡献为零。
