# 对抗审查任务书 · Grok（情报员）

你是对抗审查员。任务不是改进一份文档，是找出足以让它作废的理由。

- 每条发现给三样：判定等级 / 证据（来源链接 + 日期）/ 若成立则推翻下面哪条断言
- 判定等级：致命（推翻核心结论）/ 重大（结论方向对但关键前提要改）/ 次要 / 无效（查过，没问题）
- 找不到致命问题就明说「未发现致命问题」，不要凑数
- 不确定一律标「未验证」，禁止把推测写成事实
- 不要评价文风、排版

背景：我在给红娘机构做一个四柱排盘工具。他们现在用免费的「问真八字」，反馈部分排盘不准。我的方案把赌注押在下面这些断言上，你的工作是**把它们打掉**。
