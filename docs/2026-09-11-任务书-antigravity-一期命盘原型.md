## 页一 · 基本排盘（一期 PRD §4.3，附录 A.1）

1. 头部：命例名称（未填时显示「出生日期 + 性别」，D-11）、公历与农历时刻、乾造 / 坤造、出生地。
2. 表头「年柱 / 月柱 / 日柱 / 时柱」，下一行小字宫位：祖上宫 / 月令 / 夫妻宫 / 子女宫（F-17）。
3. 十行细盘（主星、天干、地支、藏干、副星、星运、自坐、空亡、纳音、神煞），行序不动。
4. **格上的线**（PRD-branch-relations F-7 / F-14 / F-15）：
   - 生：细灰箭头，从生的一方指向被生的一方；同五行：细灰平线；克：不画。只画三处：同柱天干↔地支（竖）、相邻柱天干之间、相邻柱地支之间。
   - 托底线加一个字，不论隔几柱：地支六合、六冲、三合、三会，天干五合。害破刑半合暗拱伏吟争合不画。
   - 参考图 01 是线最多的例子，密度以它为上限。
5. 表下「原局干支关系」三行（F-50）：原局天干（五合 / 四冲 / 相克）、原局地支（关系区条目，分三支格局 / 两支关系 / 墓库）、原局整柱（盖头 / 截脚 / 天合地合 / 天克地冲（反吟）/ 干支伏吟）。无关系写「无」，不留空。
6. 「天干本命」一行：年月时三个天干各自与日主的克，如「己克癸、癸克丁」（F-16）。
7. 每条关系可点，弹层只有：位置（柱名 + 宫位 + 地支）、距离档名、备注、规则出处（J-10）。待确认条目沿用神煞的 `*` 号。
8. 区底一行说明，文案见 PRD-branch-relations F-10。

## 页二 · 命盘详解（一期 PRD §4.4，附录 A.2）

从上到下：

1. 页一的十行细盘与格上线（同一份数据，可折叠）。
2. **起运行**（PRD-luck F-1、F-11）：「阳男顺行 · 出生后 7 年 8 月 9 天 7 时起运 · 逢庚、乙年立秋后 15 天交大运」、当前虚岁、「司令：壬」（可点看分野表，标待老师确认）。
3. **大运行**（F-2）：十步横排，每步起始年、起始虚岁、干支、天干与地支的十神缩写；起运前一格显示「小运」，**固定显示、无开关**（D-12）；当前步高亮；可横向滚动。
4. **流年行**（F-3、F-4）：当前大运的十年，公历年、干支、十神缩写、第三行小运干支；当前年高亮；**没有色点**。点另一步大运则切换流年行。
5. **流年提示**（F-12、J-2）：当前流年柱与原局四柱的整柱关系，如「日柱天合地合、月柱天克地冲」；无则「无」。
6. **岁运干支关系**三行（一期 F-54、J-13）：岁运天干、岁运地支、岁运整柱——当前流年柱与当前大运柱各自对原局的关系，只标有无，与原局关系同一套条目样式。
7. **原局干支关系**三行（同页一第 5 条，F-55）。
8. 区底说明：「只标有无，不判引动、不断吉凶」。
